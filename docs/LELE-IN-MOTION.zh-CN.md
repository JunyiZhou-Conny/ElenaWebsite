# 第四版：LeLe in Motion

入口：`/motion/`。原稿版继续保留在 `/elena/`，前两版也保持原样。

## 可以体验什么

- 首页：三个来自义乌意象的插画贴纸，可以拖动、用方向键移动；Shift 加方向键移动更远，Escape 复位，也可以点 Reset stickers 全部复位。
- 导航与邮箱：鼠标靠近时文字轻微跟随，真实可点击区域保持固定。
- Works：鼠标在作品区域移动时，浮动剧照轻柔跟随，箭头和标题也有反馈。手机保留完整可见的静态剧照，直接点开作品。
- 影片页：Stills 中的 Grid / Desk 切换在整齐网格和照片桌之间转换。Desk 中拖动 Move 手柄重排照片，点击照片放大，方向键切换，Escape 关闭。Reset 重新排好照片。

## 文件在哪里

| 文件 | 用途 |
| --- | --- |
| `content/elena.json` | 第三、四版共同使用的真实内容。改这里会同时更新两版的文案；如果只想改某一版，请明确告诉 Codex。 |
| `src/motion.mjs` | 第四版四个页面的结构 |
| `src/motion.css` | 第四版的视觉、手机排版与动效强度 |
| `src/motion.js` | 磁吸、跟随预览、拖动、网格切换和图片弹窗 |
| `public/motion/stickers/` | 三个带透明背景的 WebP 贴纸，合计约 94 KB |
| `public/elena/` | 沿用的原始 logo、字体与真实剧照 |
| `docs/MOTION-STICKER-PROMPTS.json` | 贴纸的完整生成提示词，便于以后替换 |

第四版引入原稿的基础样式，再用自己的样式覆盖。若希望只调整第四版，请勿修改 `src/elena.css`。不要直接修改 `dist/`，运行 `npm run build` 即可重新生成。

## 素材与参考

本版采用用户选中的三类交互参考：[Sticki](https://www.sticki.com.au/) 的贴纸趣味、[Denise Hermo](https://www.dehermo.com/) 的 Grid/Canvas 照片操作、[Dennis Snellenberg](https://dennissnellenberg.com/) 的磁吸与作品预览。实现为本项目新写的代码，未复制参考网站的品牌、图片或源代码。

绿叶、盒装娃娃、集装箱是 AI 生成的独立插画，以《Goodbye, Yiwu》真实剧照中的物件为题材，不是电影原始素材，也不表示新的影片情节。作品页与图片查看器使用的全部仍是 Elena 提供的真实剧照。提示词保留在本目录的 JSON 文件中。

## 维护要点

页面保持原生滚动，手机拖动只占用明确的贴纸和 Move 手柄。系统开启“减少动态效果”时停用磁吸、跟随预览与照片切换动画；主动拖动仍可使用。没有 JavaScript 时四页链接、文案和剧照网格仍可阅读，照片链接直接打开高清图。

发布前运行 `npm run build`、`npm run check`，再查看首页、作品、照片桌、弹窗与手机宽度。GitHub 的保存和网站发布是两步；继续更新现有 Site，不新建替代站点。
