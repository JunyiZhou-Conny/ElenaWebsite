# 第四版：LeLe in Motion

入口：`/motion/`。原稿版继续保留在 `/elena/`，前两版也保持原样。

## 可以体验什么

- 首页：三个来自义乌意象的插画贴纸。按下即“拿起”（阴影加深、略微放大），拖动时紧跟手指或鼠标，松手后轻轻落定；如果放在导航、logo 或文字上，会自己滑到旁边的空白处，不会挡住内容。挪动过任意贴纸后，“Pick one up.” 换成 “Put them back ↺”，点一下全部滑回原位。键盘：Tab 选中贴纸，方向键移动，Shift 加方向键移动更远，Escape 放回原位。
- 导航与邮箱：鼠标靠近时文字向鼠标轻微倾斜（导航约 6px，邮箱约 4px），真实可点击区域保持不动。当前页面的导航文字有下划线。
- Works：剧照本身就是作品的主角，静止时完整可见，不再有跟着鼠标走的浮动图片。鼠标移到这一行或用键盘选中时：剧照在画框内放大 3%，箭头转向并变橙，“View film” 变蓝并出现下划线；标题始终不动，方便阅读。点击后，这张剧照直接变成影片页的封面（浏览器支持时）。手机和平板直接显示完整剧照，点一下打开影片。
- 影片页：Stills 中的 Grid / Desk 切换会让照片从网格平滑移到照片桌并转好角度，再切回来也一样；在照片桌上的摆放会保留，只有 Reset 才会重新排好。电脑上可以按住照片任意位置拖动，单击则放大；手机上用 Move 手柄拖动，照片上下滑动仍然正常滚动页面。放大查看时可用按钮、方向键或左右滑动切换，Escape 关闭。页面末尾有回到 Works 和前往联系页的链接。
- 联系页：邮箱下方有 “Copy email address”，点一下复制邮箱，适合不用邮件客户端的访客。

## 动效节奏

所有动效共用 `src/motion.css` 顶部的三个时长和一条缓动曲线，`src/motion.js` 也读取同样的数值：

| 名称 | 数值 | 用在哪里 |
| --- | --- | --- |
| `--motion-feedback` | 160ms | 悬停、按下、颜色变化，先给出反馈 |
| `--motion-settle` | 320ms | 物体回到原位、贴纸落定、Works 剧照放大 |
| `--motion-layout` | 420ms | Grid / Desk 切换、Reset、动作结束后的回落 |
| `--ease-out` | cubic-bezier(.22,1,.36,1) | 开始快、结束轻 |

想让整体更快或更慢，只改这几个值即可，例如：“把第四版的 `--motion-settle` 改成 280ms，其余不变。”系统开启“减少动态效果”时，放大、转向、照片飞行和页面过渡都会关闭，拖动和所有功能仍可使用。

## 文件在哪里

| 文件 | 用途 |
| --- | --- |
| `content/elena.json` | 第三、四版共同使用的真实内容。改这里会同时更新两版的文案；如果只想改某一版，请明确告诉 Codex。 |
| `src/motion.mjs` | 第四版四个页面的结构 |
| `src/motion.css` | 第四版的视觉、手机排版与动效节奏（顶部的 `--motion-*` 数值） |
| `src/motion.js` | 磁吸、贴纸与照片拖动、网格切换、图片查看器、复制邮箱 |
| `public/motion/stickers/` | 三个带透明背景的 WebP 贴纸，合计约 94 KB |
| `public/elena/` | 沿用的原始 logo、字体与真实剧照 |
| `docs/MOTION-STICKER-PROMPTS.json` | 贴纸的完整生成提示词，便于以后替换 |

第四版引入原稿的基础样式，再用自己的样式覆盖。若希望只调整第四版，请勿修改 `src/elena.css`。不要直接修改 `dist/`，运行 `npm run build` 即可重新生成。

## 素材与参考

本版采用用户选中的三类交互参考：[Sticki](https://www.sticki.com.au/) 的贴纸趣味、[Denise Hermo](https://www.dehermo.com/) 的 Grid/Canvas 照片操作、[Dennis Snellenberg](https://dennissnellenberg.com/) 的磁吸与作品反馈。2026-10-07 的打磨中，Works 曾对比四种做法（更小的跟随图、固定位置的预览、增强剧照本身、剧照加跟随标签），按“标题不被遮挡、鼠标始终清楚、只出现一张剧照”的标准，选择了增强剧照本身。实现为本项目新写的代码，未复制参考网站的品牌、图片或源代码。

绿叶、盒装娃娃、集装箱是 AI 生成的独立插画，以《Goodbye, Yiwu》真实剧照中的物件为题材，不是电影原始素材，也不表示新的影片情节。作品页与图片查看器使用的全部仍是 Elena 提供的真实剧照。提示词保留在本目录的 JSON 文件中。

## 维护要点

页面保持原生滚动，手机拖动只占用明确的贴纸和 Move 手柄。系统开启“减少动态效果”时停用磁吸、放大、照片飞行与页面过渡；主动拖动仍可使用。没有 JavaScript 时四页链接、文案和剧照网格仍可阅读，贴纸只是图片，照片链接直接打开高清图。

修改 Works 一行的布局时，`src/motion.mjs` 里剧照的 `sizes` 描述了它在各宽度下的实际显示宽度；如果改了 `src/motion.css` 中 Works 的列宽，请让 Codex 一并更新 `sizes`，以免手机或高清屏下载过大或过小的图片。

发布前运行 `npm run build`、`npm run check`，再查看首页、作品、照片桌、弹窗与手机宽度。GitHub 的保存和网站发布是两步；继续更新现有 Site，不新建替代站点。
